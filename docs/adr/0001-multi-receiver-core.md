# ADR 0001 — Núcleo independente de fabricante

**Status:** Aceito no bootstrap.

O domínio da F-21 não depende de Spectra, Trimble, Leica, Topcon ou qualquer outro fabricante.
Integrações futuras entram por adapters; o modo manual permanece obrigatório.

Consequência: nenhum módulo vendor é criado no Commit 001.
